# Incident Response

## Scope

Incidents include exposure of raw captures, project packages, credentials, tenant data, release signing material, or measurement integrity defects that could produce false accepted values.

## Initial Process

1. Preserve evidence without copying unnecessary raw user data.
2. Identify affected versions, projects, tenants, and export artifacts.
3. Classify severity using the project P0 to P3 scale.
4. Stop affected releases or sync services if required.
5. Prepare remediation, regression tests, and user communication.
6. Document final root cause and prevention.
