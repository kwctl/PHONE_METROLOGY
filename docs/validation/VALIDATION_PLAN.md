# Validation Plan

## Required Reference Artifacts

- Verified length reference.
- Hole plate with multiple diameters.
- PCB coupon with known outer dimensions and hole pattern.
- Connector samples with manufacturer drawings where allowed.

## Required Evidence

- Bias.
- Repeatability.
- Reproducibility.
- Rejection rate.
- 95 percent interval coverage.
- Material and lighting matrix.
- Device and OS matrix.

No product accuracy claim is approved until this evidence exists in a versioned validation report.
